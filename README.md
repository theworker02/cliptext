# cliptext

Clip encode/decode helpers for text payloads in pipelines.

**Site:** https://theworker02.github.io/cliptext/

## Install / run

```bash
git clone https://github.com/theworker02/cliptext.git
cd cliptext
node src/cli.js
node --test
```
